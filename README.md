# 🌱 ONG Esperança Viva

Portal institucional da **ONG Esperança Viva**, desenvolvido para promover projetos de impacto social, captação de recursos e engajamento comunitário em prol da dignidade humana e sustentabilidade.

---

## 🚀 Funcionalidades

- **Página Inicial (`index.html`)**: Apresentação da missão, valores, indicadores de impacto e depoimentos.
- **Projetos Sociais (`projetos.html`)**: Catálogo detalhado das iniciativas ativas (Educação Infantil, Capacitação Profissional e Segurança Alimentar).
- **Cadastro e Voluntariado (`cadastro.html`)**: Formulário acessível para inscrição de voluntários e doadores.
- **Design System Responsivo (`css/style.css`)**: Layout moderno com CSS nativo (Flexbox e CSS Grid), paleta de cores institucional e menu acessível.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico** (acessibilidade e SEO)
- **CSS3 Moderno** (Variáveis CSS, Flexbox, Grid e Media Queries)
- **JavaScript Nativo** (validação e interatividade)
- **Git & GitHub** com metodologia **GitFlow** e **Conventional Commits**

## 💻 Como Executar Localmente

### Pré-requisitos
- Git instalado na máquina.
- Um navegador web moderno (Chrome, Firefox, Edge) ou a extensão **Live Server** no VS Code.

### Passo a Passo
1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/ong-esperanca-viva.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd ong-esperanca-viva
   ```
3. Execute a aplicação:
   - Abra o arquivo `index.html` diretamente no navegador; ou
   - Clique com o botão direito em `index.html` no VS Code e selecione **"Open with Live Server"**.
